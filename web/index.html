Local files. Local analysis.

The public site uses reference examples. To analyse local files, run this workspace from a local repository checkout.

Open the workspace on this PC ↗

Requires the local engine to be running. First-time setup:

  1. Install the project with uv sync.
  2. In web, run npm ci then npm run build.
  3. From the project folder, run uv run python -m driftwatch.workbench or use start-workspace.cmd.
  4. Open http://127.0.0.1:8765 and choose local files.

Analysis requests go to that local address. Files are processed in memory, without cloud uploads. Installing dependencies needs internet access; analysis does not.

Orbit inputs: OEM and OMM (KVN/XML), GP JSON/CSV, legacy TLE, or explicitly mapped state tables. Use “Format and column mapping” beside a file to declare its conventions.

Save a report before closing or changing the tool. Results are not stored automatically.
